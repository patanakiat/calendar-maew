# Design Brief

## Visual direction
- Professional
- Modern
- Minimalist
- Calm corporate tone
- Spacious layout with disciplined whitespace

## UI principles
- Clear hierarchy
- Strong readability
- Subtle motion only where it improves understanding
- No decorative animation
- No noisy color usage
- Use status color intentionally and consistently

## Interaction principles
- Real date selection must feel immediate and obvious
- Dialogs should open from the selected context with smooth motion
- The team overview should make shared availability obvious at a glance
- Mobile-first responsive layout with comfortable touch targets

## Accessibility
- Visible focus states
- Keyboard operability
- Meaningful labels and accessible controls
- Reasonable contrast across surfaces

## Motion
- Keep transitions short and purposeful
- Use motion only for month switching, modal entry, hover/press states, and state feedback
